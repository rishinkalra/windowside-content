# Windowside content packs

Open-data content packs for the [Windowside](https://github.com/rishinkalra/windowside) offline flight companion.

The app reads `base-world/manifest.json`. When the version there is newer than the one on the phone, it downloads only the files whose SHA-256 changed and verifies each hash before switching over.

Sources: Natural Earth (public domain), OurAirports (public domain), Noto Sans glyphs (SIL OFL). The route guides were written for Windowside (CC BY 4.0).
